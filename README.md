# Portfolio Website (React edition)

My newer portfolio is a plain HTML page at https://amitdas856.github.io (source: github.com/AmitDas856/AmitDas856.github.io). This repo keeps the earlier React version.

A personal portfolio website for Amit Das, built with React, Vite and Tailwind CSS.

## Sections
Navbar, Hero, About, Skills, Projects, Education, Certifications, Additional Skills, Contact and Footer. Dark mode is supported through Tailwind's `class` strategy.

## Tech stack
React 19, Vite, Tailwind CSS 3, react-icons.

## Run locally
```bash
npm install
npm run dev
```
Build for production with `npm run build`.

## Note
Not yet verified with a production build on a clean install; if `npm install` or `npm run dev` fails, please open an issue.
